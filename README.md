# Контрольная по Python (20 интерактивных задач)

Статичная страница: студент вводит ФИО и группу, решает 20 задач, код запускается прямо в браузере (Pyodide), проверяется скрытыми тестами. Кнопка «Завершить и отправить» сохраняет результат в Google Таблицу.

## 1. Google Таблица и Apps Script
1. Создайте Google Таблицу на Google Диске (например, «Результаты Python»).
2. Расширения → Apps Script. Удалите содержимое, вставьте код из `apps-script.gs`, сохраните.
3. Развернуть → Новое развертывание → тип «Веб-приложение».
   - Выполнять как: **Я (Me)**
   - У кого есть доступ: **Все (Anyone)**
4. Разрешите доступ (Дополнительные настройки → Перейти к проекту). Скопируйте URL, оканчивающийся на `/exec`.
5. Вставьте URL в `config.js` в константу `APPS_SCRIPT_URL`.

При изменении скрипта: Развернуть → Управление развертываниями → Изменить → Новая версия (URL сохранится).

Результаты: лист «Результаты» (Время, ФИО, Группа, Баллы, Задача1..20 = 1/0), лист «Код» — код каждого решения. Скачать как Excel: Файл → Скачать → .xlsx.

## 2. GitHub Pages
1. Создайте публичный репозиторий на GitHub и загрузите все файлы (папка `tools/` не обязательна).
   ```
   git init && git add . && git commit -m "quiz" && git branch -M main
   git remote add origin https://github.com/<логин>/python-quiz.git && git push -u origin main
   ```
2. Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save.
3. Через 1–2 минуты ссылка: `https://<логин>.github.io/python-quiz/` — раздайте студентам.

## Изменение задач
Задачи и эталонные решения — в `tools/build_and_test.py`. После правок: `python3 tools/build_and_test.py` — пересоздаёт `tasks.js` (без решений) и проверяет, что все эталоны проходят тесты.

Примечание: тесты находятся в `tasks.js` и технически видны в исходнике страницы — это нормально для учебной контрольной.
