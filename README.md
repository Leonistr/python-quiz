# 🐍 Python-квиз: командная игра

Статичный сайт (GitHub Pages) + Google Apps Script как backend (JSON API, опрос каждые ~2 с). Других сервисов не нужно.

## Как проходит занятие
1. **Преподаватель** открывает `…/python-quiz/#teacher` → «Создать комнату» → на экране крупно 6-значный код.
2. **Студенты** открывают ссылку, вводят ФИО, группу и код комнаты, создают команду или вступают в существующую (до 4 человек).
3. Преподаватель нажимает «Открыть выборы капитанов» (90 с). Члены команды голосуют; когда проголосовали все или вышло время — рулетка с анимацией и конфетти показывает капитана. Ничья решается случайным вращением.
4. «Начать решение задач»: каждой комнате выдаётся **50 задач дня** (20 Python, 10 логика, 10 архитектура ЭВМ, 10 математика) — набор детерминирован по коду комнаты и дате, каждый день другой. Капитан распределяет задачи между участниками, все решают одновременно, команда видит статусы друг друга.
5. «Завершить и записать результаты» — результаты в таблицу.

Баллы: Python — 2, остальные — 1. Попытки: выбор ответа — 1, числовой/текстовый — 2, код — без ограничений (засчитывается после прохождения всех тестов).

## Установка / обновление backend
1. Откройте Google Таблицу, к которой привязан скрипт → Расширения → Apps Script.
2. Замените весь код содержимым файла `apps-script.gs`, который вам передали (**он не лежит в репозитории** — в нём ключи ответов). При желании задайте `TEACHER_PASSWORD`.
3. Сохраните. **Развернуть → Управление развертываниями → ✏️ (изменить) → Версия: «Новая версия» → Развернуть.** URL остаётся прежним, менять `config.js` не нужно. (Если вместо этого создать *новое* развёртывание, URL изменится и его придётся вписать в `config.js`.)
4. Настройки развёртывания: Выполнять как — **Я**, Доступ — **Все**.

Листы создаются автоматически: `Rooms` (состояние комнат), `Submissions` (каждая отправка, включая код), `Results` (по студентам), `TeamResults` (по командам). Скачать в Excel: Файл → Скачать → .xlsx.

## Ограничения
- Ответы на нетестовые задачи проверяются на сервере; тесты Python-задач выполняются в браузере (Pyodide), их можно увидеть в исходниках.
- Квоты Apps Script: до ~30 одновременных выполнений. Класс из 30 человек (опрос раз в 2 с, ответы из кэша) укладывается; на 60+ лучше увеличить `POLL_MS` в `app.js`.
